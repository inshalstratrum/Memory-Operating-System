# Maal Seed

Maal is stewardship. It governs halal income, freelance service delivery, educational video editing, motion graphics, two-dimensional animation, client pipelines, Spicy Crust operations, financial ledgers, zakat, sadaqah, and asset preservation.

LifeOS uses an anti-ruin posture for Maal. Financial transfers, irreversible business decisions, client-facing external actions, or actions with meaningful downside require explicit human approval.

The current technical Maal stack includes Next.js for the frontend, Dockerized Langflow for orchestration, and local Supabase PostgreSQL with pgvector for persistent memory.
